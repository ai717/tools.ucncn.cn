| 序号 | 工具名称 | 独立页面 | 核心特色 |
| :---: | :--- | :--- | :--- |

## 🏗️ 技术架构与特性

- **100% 纯前端零后端**：数据停留在用户电脑内存沙盒中，刷新即焚，真正实现隐私安全；
- **清爽莫兰迪绿风**：沉静冷杉竹韵绿 (`#386641`) 与温润原木暖色 (`#8F6E52`)，开阔克制无弹窗；
- **SEO 友好与抗打击**：全页面配备 `Schema.org` 结构化数据（`WebApplication` + `FAQPage`）、标准 Meta、`sitemap.xml` 与 `robots.txt`。
