📖 HTML to Markdown Conversion: GFM Specs, Turndown & Clean Syntax

Created in 2004 by John Gruber and Aaron Swartz, Markdown is a lightweight markup language designed to be readable and editable as plain text while converting seamlessly into valid HTML. As modern technical documentation platforms (GitHub, Notion, Obsidian, Ghost) standardize on Markdown, converting legacy web HTML into clean Markdown is a critical data migration task.

❓ Why is ATX heading style (# Heading) preferred over Setext?

ATX-style headings prefix lines with 1 to 6 hash symbols (# to ######), clearly corresponding to HTML <h1> through <h6>. Setext style uses underlines (=== for H1 and --- for H2), which can cause visual confusion with thematic break horizontal rules.

❓ How does the parser handle complex nested HTML tables?

Standard CommonMark lacks native table specifications. Our engine implements the GitHub-Flavored Markdown (GFM) extension, translating standard HTML <table>, <thead>, and <tbody> elements into pipe-delimited tables with column alignment indicators (|:---|:---:|---:|).

❓ Does conversion remove tracking tags and inline CSS?

Yes! Web pages often contain excessive styling clutter: style="font-size:14px;color:#333;margin:0;", tracking pixels, and empty <div> wrappers. Our parser strips presentation noise, extracting only semantic structural elements.
