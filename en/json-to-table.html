📖 Working with JSON: Data Structures, Flattening & CSV Exports

JSON (JavaScript Object Notation) is the universal standard for web API responses, database dumps, and configuration files. While lightweight for computers to exchange, raw JSON structures with nested keys can be difficult for humans to inspect and analyze. Converting JSON into tabular data enables spreadsheet filtering, charting, and accounting audits.

❓ Why do CSV files sometimes open with garbled characters in Microsoft Excel?

When Microsoft Excel opens CSV files without a UTF-8 Byte Order Mark (BOM), it assumes the system's legacy ANSI code page, causing non-ASCII characters to display as garbled symbols. Our exporter prepends a standard UTF-8 BOM (﻿) to ensure seamless compatibility with Excel, Google Sheets, and Numbers.

❓ How does object flattening work for nested JSON?

If your JSON contains nested child objects like {"user": {"name": "Alice", "city": "Seattle"}}, our parser extracts the child values and creates composite column headers like user.name and user.city, preserving hierarchical context in a 2D table.
