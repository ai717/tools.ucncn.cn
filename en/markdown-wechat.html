📖 Rich Text Publishing: Markdown Inlining, Newsletters & Typography

Publishing high-quality long-form articles across newsletter platforms (Substack, Mailchimp, Ghost), blogging networks (Medium, LinkedIn Articles), and closed CMS portals often causes frustrating formatting issues. When pasting content, external CSS stylesheets are discarded. Our formatter compiles Markdown into self-contained HTML elements containing calculated inline styles.

❓ How does One-Click Rich Text Copy work without losing styles?

When you click "Copy Rich Text", our utility writes directly to the system clipboard using the modern ClipboardItem API with the text/html MIME type. The receiving rich-text editor (in WordPress, Substack, or WeChat) interprets the inline CSS properties directly, preserving typography, margins, and accent colors without degradation.

❓ What are the key typography rules for comfortable mobile reading?


• Font Size: 15–16px ensures optimal legibility on modern high-DPI smartphone displays.
• Line Height: 1.75 to 1.85 provides adequate vertical rhythm to reduce eye fatigue.
• Paragraph Spacing: 16–20px spacing between paragraphs prevents walls of text.
• Color Contrast: Morandi muted greens and warm charcoals (#1d2b22) reduce harsh glare compared to pure black (#000000).

❓ Is my draft saved if my browser crashes?

Yes. The editor continuously synchronizes your work into the browser's persistent localStorage database. Even if you accidentally refresh or close the browser window, your writing will be automatically restored.
