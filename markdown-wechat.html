📘 为什么直接把 Markdown 粘贴到微信公众号后台会格式错乱？

一、微信公众号富文本沙盒的特殊性

微信公众号后台的编辑器不支持读取任何 <style> 标签或外部 CSS 文件。当您从常规 Markdown 网站直接复制代码时，由于丢失了样式表定义，粘贴进微信后台后，标题字体过大、代码块丢失底色、引用块边框消失，原本漂亮的排版会彻底变成毫无美感的素文本。

二、“不烧心”一键行内样式注入机制

本工具在浏览器渲染 Markdown 时，会自动将排版色彩、内边距、字号与圆角样式，逐一注入到每一个标签的 style="..." 属性中（即 Inline Style）。
点击“一键复制微信富文本”后，剪贴板会同时写入高标准的 HTML 富文本包，无论您粘贴至微信公众号、知乎专栏、飞书文档还是邮件客户端，格式都能做到 100% 完美保真。

三、打造高质感公众号排版的黄金建议

  • 留白适度：段落之间保持 1.5 到 1.75 倍行高，每段控制在 3~5 句话以内，避免大篇密不透风的文字压迫感；
  • 主色克制：整篇文章的主题色不要超过两种。推荐使用沉静的莫兰迪绿或高级炭黑，突出文字本身的质感。
