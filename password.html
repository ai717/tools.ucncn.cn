📘 为什么生成安全密码必须使用纯本地密码学随机数 (CSPRNG)？

一、为什么千万不能用普通的在线密码生成器？

市面上很多所谓的密码生成网站，把用户生成的密码发往了它们的后端服务器。如果您在这个网站上生成了银行账户、服务器 root 口令或企业管理员密码，该网站的站长在后台日志中能清清楚楚看到该密码，甚至与您的 IP 地址相关联，带来灾难性的安全风险。

二、Math.random() 与 window.crypto 的天壤之别

许多劣质小工具使用浏览器自带的 Math.random() 来挑选随机字符。但科学界早已证实：Math.random() 是非密码学安全的伪随机数发生器，攻击者只需截获一两个生成的口令，就能逆向计算出内部种子的线性同余状态，推算出后续所有密码。
本工具严格调用 window.crypto.getRandomValues()，直接从操作系统底层的熵池（如鼠标移动轨迹、硬件时钟微抖动）获取真随机源，具备不可逆与抗推导特性。

三、排除易混淆字符对打工人的意义

在很多等宽字体或便签纸上，1（数字一）、l（小写 L）、I（大写 i）很难分辨；数字 0 与大写字母 O 也经常让人误输导致账号被风控锁定。开启本工具的“排除容易混淆字符”选项后，密码依然具备数十万年难以暴力破解的高熵值，同时免去人工抄写辨析的痛苦。
